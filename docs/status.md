# Текущее состояние LOB Lab

Обновлено **2026-10-31**. Цель проекта — исследование краткосрочного движения
mid-price по состоянию стакана; роли Python/C++ описаны в [README](../README.md).
Восемь этапов и критерии — в [roadmap](roadmap.md), формулы — в [decisions](decisions.md).

## Текущий этап

плановый этап — **2, исследование состояний стакана; он не начат**. Этапы 3–8
также не начаты. Первая ML-версия (этапы 1–4) ещё не завершена.

не означают наличия генератора признаков/меток, обученных моделей или C++-стакана.

## Известные проблемы и ограничения

- Строка 67823 имеет 12 дробных знаков времени. Сохранена точно через Decimal;
  `time_ns` для неё не представим точно и возвращает `None`. Правило для C++
  пока не выбрано. При `report --sample --strict` замечание означает код 1.
- Один день AMZN и глубина 5 ограничивают обобщение результатов и не дают
  полного потока отдельных заявок. Для C++ запланирован отдельный искусственный поток.
- Право на перепубликацию исходных данных или коммерческое использование
  проверкой не подтверждено; подробности и дата проверки в [data-source](data-source.md).
- Время, спред и типы событий из отчёта — описательные агрегаты, а не оценка
  прогнозируемости. Горизонт, признаки, части данных и log-loss пока только согласованы.
