# LOB Lab

Учебный проект исследования биржевого стакана. Первый этап — точная загрузка и
проверка одного официального образца **LOBSTER AMZN, 2012-06-21, 5 уровней**.
Дальнейшие этапы: C++-обработчик событий и ML-модели. На этом этапе обучения нет.
Теоретические заметки остаются за автором проекта.

## Запуск

Нужен Python **3.11+**. Все команды выполняются из корня репозитория;
загрузчик, отчёт и тесты используют только стандартную библиотеку.

```bash
# Один официальный ZIP; проверка SHA-256 архива и всех извлечённых файлов.
python3 -m lob_lab fetch

# Полный отчёт в терминале, JSON и Markdown.
python3 -m lob_lab report --sample \
  --json reports/amzn-2012-06-21-l5.json \
  --markdown reports/amzn-2012-06-21-l5.md

# Искусственный корректный пример без сети.
python3 -m lob_lab report \
  --message tests/fixtures/valid/message.csv \
  --orderbook tests/fixtures/valid/orderbook.csv --levels 5 --strict

# Тесты без доступа к исходным данным и сети.
python3 -m unittest discover -s tests -v
```

Для своих файлов задайте `--message PATH --orderbook PATH --levels 5` вместо
`--sample`. Команда `report` не скачивает данные; сначала нужен `fetch`.
Повторный `fetch` сверяет локальные контрольные суммы без загрузки. Если архив
или извлечённый файл изменён, команда сообщает ошибку и сохраняет его для разбора.
Несовпадение checksum нового скачивания также останавливает распаковку.

Коды завершения: **0** — отчёт сформирован; **1** — отчёт сформирован, но при
`--strict` есть замечания; **2** — ошибка аргументов, доступа или загрузки.
Для официального образца `--strict` возвращает 1: найдена одна временная метка
с точностью выше заявленной наносекунды. Она сохранена точно и включена в метрики.

код, документация, манифест, агрегированный отчёт и собственные искусственные
примеры; исходные биржевые строки не публикуются.

## Результат первого этапа

По **155 935** строк в каждом файле; ошибок числа столбцов, представления цен,
порядка времени/уровней, отрицательных/нулевых объёмов и пустых/locked/crossed
стаканов не найдено. Одна строка отмечена за 12 знаков после точки во времени.
Диапазон: **34200.017459617–57599.95935965** секунд от полуночи биржи.
Медианный спред — **$0,13**, p95 — **$0,23**; **27 557** изменений mid-price.
Полное распределение событий и спреда приведено в отчёте.

Загрузчик не сортирует и не удаляет строки. Каждая ошибка получает причину,
счётчик и примеры номеров строк; непарные хвосты файлов тоже учитываются.
